Project Title: COVID-19 Global Data Tracker

Project Description

Build a data analysis report or interactive app that tracks global COVID-19 trends using real-world public health data. The project should clean and process country-level data, analyze changes in cases, deaths, and vaccination coverage over time, and communicate findings through clear visualizations and concise narrative insights.

Project Objectives

- Import and clean COVID-19 global data.
- Analyze time trends for cases, deaths, and vaccinations.
- Compare metrics across countries and regions.
- Visualize trends with charts and maps.
- Communicate findings in a notebook, report, or interactive dashboard.

Recommended Data Source

- Our World in Data COVID-19 dataset: owid-covid-data.csv
- Alternative source: Johns Hopkins University COVID-19 data repository

Recommended Workflow

1. Data Collection
   Obtain a reliable COVID-19 dataset and save it in the project folder.

2. Data Loading and Exploration
   Load the dataset with pandas, inspect the columns, preview records, and review missing values.

3. Data Cleaning
   Convert date fields to datetime values, filter selected countries or regions, and handle missing values in critical metrics.

4. Exploratory Data Analysis
   Analyze cumulative cases, cumulative deaths, daily or smoothed new cases, and case fatality ratios.

5. Vaccination Analysis
   Compare vaccination progress across selected countries using cumulative totals or population-adjusted vaccination rates.

6. Geographic Visualization
   Create an optional choropleth map using ISO country codes and the latest available case or vaccination metrics.

7. Insights and Reporting
   Summarize the most important findings, highlight notable differences between countries, and explain any data limitations.

Key Columns

- date
- location
- iso_code
- total_cases
- new_cases
- total_deaths
- new_deaths
- total_vaccinations
- people_fully_vaccinated_per_hundred
- population

Recommended Tools

- Python
- pandas
- matplotlib or seaborn
- Plotly
- Jupyter Notebook, Streamlit, or another reporting interface

Expected Deliverables

- A cleaned and documented analysis workflow.
- Visualizations comparing COVID-19 trends across countries.
- A short written summary of findings.
- Optional exportable artifacts such as an HTML dashboard, PDF report, or presentation-ready charts.

Optional Extensions

- Add user-selectable countries and date ranges.
- Build an interactive dashboard with Streamlit or Dash.
- Include hospitalization or ICU metrics where available.
- Add data-quality notes for missing or stale metrics.
